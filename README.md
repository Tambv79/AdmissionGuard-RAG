# AdmissionGuard-RAG — GitHub Release Candidate 2

Research artifact for **Cost-Aware and Safety-Grounded RAG for Vietnamese University Admission Question Answering**.

## Important provenance
- The main TEST/STRESS one-shot results remain frozen and unchanged.
- `results/post_review_*` contains a separately labeled deterministic repair analysis; it is not part of the original one-shot result.
- The public-safe corpus package excludes the original institutional PDF files. It retains structured/normalized research artifacts, source metadata, public URLs, and checksums where available.
